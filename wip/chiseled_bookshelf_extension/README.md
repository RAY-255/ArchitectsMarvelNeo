# WIP: Chiseled Bookshelf Extended Accepted Items

Этот WIP добавляет в `minecraft:bookshelf_books` новые предметы:

- все `#minecraft:banner_patterns`
- `minecraft:experience_bottle`
- `minecraft:ominous_bottle`

## Как включить

Перемести папку `data/` из этого WIP в рабочие ресурсы проекта:

- либо в `src/main/resources/`
- либо в `src/generated/resources/` (если хочешь через datagen-цикл)

Текущий WIP **не активен**, пока находится в `wip/`.
